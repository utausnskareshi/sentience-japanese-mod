# Sentience: The Android's Tale 非公式日本語化パッチ

Steam 版「Sentience: The Android's Tale」を日本語で遊べるようにする、非公式の日本語化パッチです。

> [!IMPORTANT]
> 本パッチは有志による非公式のものです。開発元（Pilgrim Adventures）・販売元（GrabTheGames）とは一切関係ありません。
> 本パッチについて開発元・販売元へ問い合わせないでください。

## 特徴

- **ボタン 1 つで日本語化・元に戻す**：パッチツールを起動して「日本語化する」を押すだけです。「元に戻す」で適用前の状態に完全に戻ります。
- **ゲームのファイルをほとんど書き換えない**：翻訳用のプラグインと訳文データを追加し、プラグイン一覧（`www/js/plugins.js`）に 1 行登録するだけです。会話データや画像・音声などのファイルは変更しません。
- **セーブデータはそのまま使える**：日本語化の前後で同じセーブデータを使えます（セーブデータに日本語を書き込まない仕組みです）。
- **ゲーム内で英語と切り替え**：オプション画面の「言語 / Language」で、いつでも日本語と英語を切り替えられます。
- **ランタイム同梱**：配布 Zip の exe 1 つで動きます。.NET などのインストールは不要です。

## 動作環境

- Windows 10 / 11（64bit）
- Steam 版「Sentience: The Android's Tale」（動作確認: Steam ビルド 2476493）

## 使い方

1. [Releases](../../releases) から `SentienceJP-Patcher-vX.Y.Z.zip` をダウンロードし、任意のフォルダに展開します。
2. ゲームを終了した状態で `SentienceJP-Patcher.exe` を起動します。
   - ゲームのインストール先は自動で検出します。見つからない場合はメッセージを表示して終了します。
3. 「日本語化する」を押します。完了したらゲームを起動してください。

元に戻すときは、同じツールを起動して「元に戻す」を押します。

### Windows の警告（SmartScreen）が表示された場合

本ツールにはコード署名がないため、初回起動時に「Windows によって PC が保護されました」と表示されることがあります。
配布元が本リポジトリであることを確認のうえ、「詳細情報」→「実行」を選んでください。
配布物の SHA-256 は Releases の `SHA256SUMS.txt` に記載しています。

### ゲームのアップデート・整合性チェックの後

Steam のアップデートや「ゲームファイルの整合性を確認」により、日本語化が外れることがあります。
その場合はツールを起動すると「再適用する」ボタンが表示されるので、押してください。

## 翻訳について

- 翻訳は生成 AI（Claude）によるものです。誤訳や不自然な表現が含まれる可能性があります。
- 画像に描かれた英語（イントロの見出しやエリアマップのラベルなど）は、画像の上に日本語のラベルを重ねて表示しています。タイトルロゴなど一部は原文のままです。
- Steam の実績名・説明は Steam 側のデータのため翻訳できません。

## 仕組み

- パッチツールは、`www/js/plugins/SentienceJP.js`（翻訳プラグイン）と `www/sentience_jp/`（訳文データ）を追加し、`www/js/plugins.js` に 1 件登録します。元の `plugins.js` は `sentience_jp_backup/` にバックアップし、「元に戻す」で復元します。
- 翻訳プラグインは、ゲームが文章を表示する直前に訳文へ差し替えます。日本語の文字は、ゲームに同梱されているフォント（M+ 1m）で表示します。
- 訳文データは「原文のハッシュ値 → 訳文」の形式で、原文（英語）は含みません。
- ゲームの暗号化された画像・音声は復号しません。

## 開発者向け

| 用途 | コマンド |
| --- | --- |
| 依存パッケージのインストール | `npm ci` |
| 型チェック・テスト | `npm run typecheck` / `npm test` |
| 原文の抽出（各自のゲームから。出力は Git 管理外の `work/`） | `npm run extract` |
| 訳文の検証 | `npm run verify` |
| ペイロードの生成 | `npm run build` |
| パッチツールのテスト・exe 作成 | `patcher\build.ps1` |
| 配布 Zip の作成 | `npm run package` |
| ブラウザでの表示確認（ゲームフォルダには書き込まない） | `npm run build && npm run dev` |

リポジトリには原文を含めないでください（`work/` は `.gitignore` 済みです）。
